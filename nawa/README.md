# نَواة | NAWA

واجهة MVP عربية ومتجاوبة للمكتب الهندسي السحابي الذكي. تستخدم لوحة الألوان أخضر النخيل مع درجات الرمل والذهبي الهادئ، مع إبقاء ألوان الحالات واضحة.

## تشغيل النموذج

افتح `index.html` في متصفح حديث، أو شغّل خادم ملفات محليًا من جذر المستودع:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000/nawa/`.

## ما يتضمنه العرض

- لوحة مكتب تعرض المشاريع والتنبيهات والأولويات بوضوح.
- صفحات المشاريع والمهام والملفات والاعتمادات والفريق.
- خريطة تفاعلية لترابط الطلبات والقرارات والملفات والمهام.
- تحليل أثر توضيحي مع مصادره والمعلومات الناقصة، ثم مقترح تصميم منفصل يتطلب مراجعة مهندس.
- مساعد مشروع عربي بإجابات عرض تجريبية مع مصادرها.
- معاينة الأدوار: مديرة المكتب، مهندسة، عميلة.
- إنشاء مهام ومشاريع وقرارات عبر نماذج واجهة توضيحية.

## حدود نسخة MVP الحالية

البيانات مضمّنة للعرض. لا يوجد تسجيل دخول حقيقي، قاعدة بيانات، رفع ملفات، إرسال إشعارات، أو اتصال بمزود ذكاء اصطناعي. يلزم بناء API وخدمات تخزين وصلاحيات قبل استخدامها مع بيانات مشاريع حقيقية. لا تُعامل مقترحات التحليل كاعتماد هندسي.

الخطوة التالية هي ربط الواجهة بخلفية آمنة ومزود AI واحد عبر واجهة خادم، مع صلاحيات بحسب الدور وسجل تدقيق ومراجعة بشرية.
