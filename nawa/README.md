# نَواة | NAWA

واجهة MVP عربية ومتجاوبة للمكتب الهندسي السحابي الذكي.

## تشغيل النموذج

افتح `index.html` مباشرة في متصفح حديث، أو شغّل خادم ملفات محليًا من مجلد المشروع:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000/nawa/` إذا شغّلته من جذر المستودع.

## ما يتضمنه العرض

- لوحة المكتب وموجز تنبيهات مستند إلى سجلات العرض التجريبية.
- مساحات المشاريع، المهام، الملفات، الاعتمادات والفريق.
- خريطة تفاعلية للخيط الهندسي وعلاقات الطلبات والقرارات والإصدارات.
- تحليل أثر تجريبي للتغييرات، ومقترح تنسيق وتصميم مع اعتماد بشري.
- مساعد مشروع عربي بإجابات توضيحية مرتبطة بمصادر بيانات العرض.
- تبديل أدوار للمعاينة: مديرة المكتب، مهندسة، عميلة.
- إنشاء مهام ومشاريع وقرارات عبر نماذج واجهة توضيحية.

## حدود نسخة MVP الحالية

البيانات المعروضة تجريبية ومضمّنة في الواجهة. لا يوجد تسجيل دخول حقيقي، قاعدة بيانات، رفع ملفات فعلي، إرسال إشعارات، أو اتصال بمزود ذكاء اصطناعي. يلزم بناء API وخدمات تخزين وصلاحيات قبل استخدامها مع بيانات مشاريع حقيقية. لا تُعامل مقترحات التحليل كاعتماد هندسي.

الخطوة التالية هي ربط الواجهة بخلفية آمنة ومزود AI عبر واجهة خادم، مع صلاحيات بحسب الدور وسجل تدقيق ومراجعة بشرية.
